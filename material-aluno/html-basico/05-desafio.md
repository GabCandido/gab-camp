
# Desafio: depurando uma página de adoção de animais

Uma organização de adoção de animais está preparando uma página para apresentar seus gatos e orientar os visitantes sobre como conhecer os animais disponíveis.

O conteúdo da página já foi escrito, mas alguns problemas no código impedem que os elementos funcionem corretamente.

Sua tarefa é investigar o HTML e corrigir os problemas encontrados.

## 1. Preparando o projeto

1. Crie uma pasta chamada `adocao-animais`.
2. Abra essa pasta no Visual Studio Code.
3. Crie um arquivo chamado `index.html`.
4. Insira a estrutura básica de um documento HTML.

## 2. Código inicial

Dentro do `body`, insira o seguinte conteúdo:

```html
<h1>Adote um animal!</h1>

<p>Encontre um novo companheiro. Temos gatos e cães esperando por um lar.</p>

<h2>Conheça nossos gatos</h2>

<img href="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg" att="Cinco gatos reunidos em um campo."></img>

<h2>Adote um gato</h2>

<a src="/gatos">Conheça os gatos disponíveis</a>

<h2>Adote um cão</h2>

<a src="/caes">Conheça os cães disponíveis</a>
```

## 3. O desafio

Investigue o código e faça as correções necessárias para que os elementos HTML funcionem como esperado.

A página deverá apresentar:

- Um título principal e um parágrafo introdutório.
- Um título para a seção de gatos.
- Uma imagem acompanhada de um texto alternativo.
- Um título para a seção de adoção de gatos e um link correspondente.
- Um título para a seção de adoção de cães e um link correspondente.

**Importante:** preserve os textos e a organização do conteúdo. Concentre-se na correção da estrutura HTML e dos atributos utilizados.

Não é necessário criar as páginas de destino dos links.

## 4. Verificação

Abra a página com o Live Server e confira o resultado no navegador.

Ao concluir, verifique se:

- A imagem é exibida corretamente.
- A imagem possui um texto alternativo.
- Os links possuem seus respectivos destinos.
- Os elementos estão utilizando os atributos adequados.
- O código respeita a estrutura dos elementos HTML utilizados.
