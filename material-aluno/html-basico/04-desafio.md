
# Desafio: corrigindo uma página de perfil

Neste desafio, você recebeu o código inicial de uma página de perfil pessoal criada por uma estudante chamada Lia.

A página deveria apresentar um título principal, uma seção sobre a estudante e outra sobre seus interesses e hobbies. Entretanto, o código ainda não está funcionando como esperado.

Sua tarefa é investigar o código e corrigir os problemas encontrados.

## 1. Preparando o projeto

1. Crie uma pasta chamada `perfil-pessoal`.
2. Abra essa pasta no Visual Studio Code.
3. Crie um arquivo chamado `index.html`.
4. Insira a estrutura básica de um documento HTML.

## 2. Código inicial

Dentro do `body`, insira o seguinte conteúdo:

```html
<h1>Olá! Eu sou a Lia.</h1>

<heading2>Sobre mim</heading2>

<pp>Meu nome é Lia e gosto de aprender coisas novas.</pp>

<h3>Interesses e hobbies<h3/>
<pp>Gosto de resolver desafios e criar projetos.</pp>
```

## 3. O desafio

Investigue o código e faça as correções necessárias para que a página apresente corretamente todas as informações.

A estrutura final deve conter:

- Um título principal com a apresentação da Lia.
- Um subtítulo chamado "Sobre mim".
- Um parágrafo com uma breve apresentação.
- Um título de seção chamado "Interesses e hobbies".
- Um parágrafo descrevendo seus interesses.

**Importante:** preserve os textos e a organização do conteúdo original. Seu trabalho é corrigir a estrutura HTML, não reescrever as informações.

## 4. Verificação

Abra a página com o Live Server e confira se o conteúdo aparece corretamente no navegador.

Ao concluir, verifique se:

- Todos os títulos utilizam elementos HTML apropriados.
- Os parágrafos estão representados corretamente.
- As tags estão abertas e fechadas de maneira adequada.
- A hierarquia dos títulos foi preservada.
